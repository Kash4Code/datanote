Project Folder Structure

├── package.json               # Dependencies & build scripts

│   │   └── DevToolsModal.tsx  # Quick dev utilities (JSON formatter, Regex, etc.)
│   ├── engines/
│   │   └── duckdbWorker.ts    # WebAssembly DuckDB query execution logic
│   └── styles/
│       └── globals.css        # Tailwind CSS & theme definitions
